# Java Backend Career Restart

This repository tracks my structured preparation for returning to a hands-on Java backend engineering role.

The focus is on rebuilding practical coding confidence through Java exercises, data structures and algorithms, SQL, testing, backend design, and interview preparation.

## Current Focus

- Java fundamentals and modern Java practices
- Collections, Streams, Optional, and object equality
- JUnit testing
- Data structures and algorithms
- SQL and database fundamentals
- Spring Boot and REST APIs
- Messaging and distributed-system concepts
- System design and interview preparation

## Tech Stack

- Java 21
- Maven
- JUnit 5
- Git

Additional technologies will be added only after they are used in hands-on exercises or projects.
